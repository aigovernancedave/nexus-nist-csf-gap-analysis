# 🏦 Nexus Financial Services: Mapping NIST CSF 2.0 to Business Processes

A GRC case study in which I conducted a NIST Cybersecurity Framework (CSF) 2.0 gap assessment for a simulated FinTech organization. 
I mapped CSF 2.0 Functions to core business processes, identified key gaps between Current and Target Profiles, mapped each gap to a NIST SP 800-53 control family, and delivered a phased Framework Implementation Plan.

# The Scenario 📊

Nexus Financial Services employs **250 people** across three offices and business areas:

**IT & Operations:** infrastructure, cloud hosting, and data centres 💻

**Finance & Compliance:** customer data, transactions, regulatory reporting 💸

**Human Resources:** employee records and third-party contractor data 👥

**Systems in scope:**
Cloud-hosted customer data (AWS), payment systems, mobile banking app, third-party API integrations, and on-prem Active Directory.


# The Business Problem ⚠️
Nexus handles highly sensitive financial data but lacks a structured, outcome-based cybersecurity risk program mapped to NIST CSF 2.0.

<img width="782" height="236" alt="image" src="https://github.com/user-attachments/assets/ac457e75-c7c7-420b-8132-080a942c5a07" />


**Business impact:**

Higher risk of breaches

Potential regulatory penalties

Limited executive insight into risk posture

No shared language to describe risk to the board


# Objectives 🎯

Map 5 business processes to CSF Functions that protect them

Identify one gap per process between Current and Target Profile

Recommend one NIST SP 800-53 control family per gap

Phase the remediation actions in an implementation plan

State the current Implementation Tier

# Tools 🛠️

NIST Cybersecurity Framework (CSF) 2.0

NIST SP 800-53 Rev. 5 control families

Google Docs & Sheets
